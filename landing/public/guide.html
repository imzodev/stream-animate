01

Get started

Saidcue sits in your system tray and listens. A phrase only becomes a command when it starts with the wake word, so talking on a call or on stream never clicks anything.

  1. Turn it on. Right-click the tray icon, open Settings, go to the Voice Commands tab and tick Enable voice commands.
  2. Pick a wake word. Choose computer, hey computer, assistant, hey assistant or companion, or type your own. Two-word wake words misfire less, because ordinary sentences rarely start with them.
  3. Say a command. Wake word first, then the command: computer, scroll down. You can pause after the wake word; Saidcue waits a few seconds for the rest.
  4. Watch the pill. The small on-screen pill confirms every command with a check mark, says what went wrong with a cross, or shows “Thinking…” while the AI works.
Tip

Every command has a checkbox in the Voice Commands tab, so you can switch off any you don't want. The Commands guide button there opens a searchable list inside the app.

In the examples below, computer, … stands for your wake word. Words in italics are things you fill in, like an app name or a number. Numbers can be spoken (“twelve”) or understood as digits (“12”), whichever your speech engine writes.

02

Open and close apps New

Any app in your Start menu opens by name, both desktop programs and Store apps. Saidcue reads the Start menu list in the background, so new installs show up within a few minutes.

  • computer, open obsStarts OBS Studio. “launch”, “start”, “run” and “abre” work too.
  • computer, open visual studioSeveral apps match, so a numbered list appears. Say two to pick, or click one.
  • computer, open github dot comA name that ends in a web domain opens the site in your browser.
  • computer, close spotifyCloses that app's window, found by its title or program name. Apps still ask to save your work.
  • computer, open settingsWindows Settings. open file explorer opens Explorer.

The built-in shortcuts open youtube, open twitch, open notepad and open calculator still work as before. If nothing matches the name, the request goes to the AI fallback when you have it turned on.

Keys and shortcuts New

Say any key or shortcut, with “press” or on its own. Add “3 times” or “twice” to repeat it.

  • computer, press control shift tPresses Ctrl+Shift+T. “hit”, “tap” and “key” work in place of “press”.
  • computer, escapeA key name on its own presses it.
  • computer, backspace five timesRepeats the key, up to 50 times.
  • computer, alt f4Any combination of modifiers and a key.
  • computer, press windowsThe Windows key on its own.
  • computer, press save“Save” isn't a key name, so this clicks the button labelled Save instead.

Key names Saidcue knows

Modifiers:

Keys:

Letters and digits count only after a modifier (control z, alt 1), so a stray “a” or “you” is never pressed. Speech engines mishear single letters, so the phonetic alphabet works as well: control charlie is Ctrl+C. Some Spanish names work too: borrar, espacio, intro, arriba, abajo.

Dictation

  • computer, dictate in notepadBrings Notepad to the front and starts typing what you say.
  • computer, start dictationTypes into whatever window is in front. stop dictation ends it.

With Dictation editing turned on, a few phrases work while you dictate without the wake word, but only when the whole phrase is the command, so a sentence that contains them is still typed: new line, new paragraph, scratch that (erases the last phrase), delete word, select all, press enter and stop typing.

06

Click by name

Say the label you see on a button, link, menu item, checkbox or text box. Saidcue finds it through Windows UI Automation, which also sees web pages in your browser, and the mouse doesn't move.

  • computer, click subscribePresses the button or link labelled Subscribe.
  • computer, click searchFor a text box, puts the cursor in it so you can dictate.
  • computer, right click report.pdfOpens the right-click menu on it. New
  • computer, double click my documentsDouble-clicks it, to open a file or folder. New
  • computer, skip adClicks YouTube's Skip button, in English, Spanish, Portuguese, French or German.

Exact labels win over partial ones, so click skip picks Skip, not Skip navigation. If several buttons share the label, such as a Reply under every comment, Saidcue doesn't guess: it puts numbers on just those buttons and waits for you to say one. New

To stop a stray command from closing your browser, the browser's own Close and Minimize buttons and the buttons on each tab are never clicked by voice. Use close tab or close window for those.

08

Mouse grid: point anywhere New

Games, drawing apps, video players and remote desktops don't tell Windows what's on screen, so there is nothing to name or number. The mouse grid works on any pixel.

  1. Say computer, mouse grid for the whole screen, or computer, window grid for just the window in front. A 3×3 grid appears.
  2. Say the number of the cell that has your target. The grid zooms into that cell and the mouse follows its centre. Two or three numbers reach any spot. 53 zooms twice in one go.
  3. Say what to do there: click, right click, double click, middle click, or move to just leave the mouse there. click 7 zooms into 7 and clicks.

To drag, zoom to the start point and say mark. The grid goes back to full size; zoom to the drop point and say drag here.

back or zoom out undoes one zoom. cancel closes the grid. While it's up, none of these need the wake word.

11

AI assistant and AI agent

Two different things: ask the AI a question and read the answer, or hand it a job on your PC that no single command covers.

Ask a question

  • computer, ask how tall is everestThe answer streams into the AI panel. “explain…”, “what is…”, “who is…”, “why…” and “how…” work the same way.
  • computer, ask a questionStarts listening; then say the question.

Let the AI do it New

Turn on Ask the AI when a command isn't in the list. Then any wake-word phrase that isn't a command goes to the AI, which works through it step by step: it looks at the window, acts, looks again, and stops when the job is done.

  • computer, in notepad turn on word wrapGoes to Notepad, opens the Format menu, clicks Word Wrap.
  • computer, open paint and make the canvas biggerOpens the app, then finds the right menu.
  • stopStops the AI at any point, without the wake word. So does Ctrl+Alt+Backspace.

The pill shows each step as it happens (“Step 2: clicked Format”). The AI runs in the background, so you can keep talking and start other commands. It takes at most 6 steps per request unless you change that.

What the AI can and can't do

  • It clicks by name. It is told the names of the buttons, links and boxes in the window in front, and can click those. You can turn clicking off with Let the AI click buttons and menus.
  • It asks before risky clicks. A click on anything that sounds like delete, buy, pay, send, post, publish, install, sign out, close or the like asks first: “Click ‘Delete’? Say yes or no”. Nothing happens unless you say yes within 20 seconds. no, or silence, skips it.
  • It never presses Enter, never types into a terminal, never runs programs or shell commands, and can't click blindly at a spot it hasn't seen.
  • It can't open the number labels, the mouse grid or the window list; those wait for you.

AI vision (optional, off by default) New

For things without a name, like icons, games and canvases, turn on Let the AI look at screenshots. The AI can then take a screenshot of the window in front and click a spot it can see. It still prefers names when there are any, and risky clicks are still confirmed.

What goes to your AI provider

Your request, the titles of your open windows and the names of browser tabs. With clicking on, also the names of the buttons and boxes in the window in front. With vision on, also screenshots of that window, so leave vision off if your screen may show private things. Vision needs a model that accepts images. Built-in commands never send anything.

16

Limits and fixes

A command doesn't do anything

Check that the phrase starts with the wake word; the pill shows what it heard. If your speech engine often mishears the wake word, try a two-word one like “hey computer”. If the pill shows a cross, its message says why, for example “Nothing called ‘subscribe’ here”.

Nothing happens in Task Manager or an installer

Windows doesn't let a normal app control windows that run as administrator, such as Task Manager, installers, and some game launchers. Voice commands can't click or type into those. If you need to, run Saidcue as administrator.

“Click …” can't find a button I can see

The button probably has no name, or a different one than the text suggests. Say show numbers and pick its number. If it doesn't get a number, the app draws its own interface (games, some media apps, remote desktops): use the mouse grid, or the AI with vision on.

Scrolling doesn't work in Firefox

Firefox doesn't support Windows UI Automation scrolling, so Saidcue scrolls with the mouse wheel over the middle of the window and puts the pointer back.

The numbers are in the wrong place

That can happen on setups with two monitors at different display scaling. Please report it on GitHub with your scaling settings. The mouse grid still works.

Which languages work?

Commands are in English, with Spanish forms for common ones (“abre”, “cierra”, “presiona enter”, numbers like “dos” and “tres”). Dictation works in any language your speech model supports.

Does this work on Linux?

Not yet. Voice commands use Windows UI Automation, so they are Windows only for now. Dictation, voice triggers and the AI assistant work on Linux.
